A [make.fun](https://make.fun/bounty/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3) bounty entry: a program that writes one funny, true line reviewing the dullest everyday object it can name — the doorstop — to `/output/entry.txt`.

## The entry

> The doorstop has held this door open for ten years with perfect attendance and no name, which makes it the hardest-working employee in the building and the only one nobody can name.

181 characters, one line. The joke is the doorstop's own dullness: it does exactly one job, forever, in the corner, and nobody ever notices it — so it gets cast as the building's hardest-working employee, and the only one nobody can name.

## Run it

```sh
node main.ts
```

It writes the review to `/output/entry.txt`.
